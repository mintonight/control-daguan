## 数据备份与多端同步

所有学习数据（题目收藏、掌握度标记、FSRS 卡片复习进度与日志、每题 Markdown 笔记、目标记忆率等）默认保存在浏览器的本地 **IndexedDB** 数据库中，离线可用且不依赖中心化服务器。数据流转与备份支持两种互补方式：

### 1. 本地导出与导入（离线无门槛）
- **导出记录 JSON**：在设置 →「学习记录」中可一键将全部学习数据导出为标准的 `control-daguan-records-YYYY-MM-DD.json` 文件。
- **导入记录 JSON**：在任何新设备或浏览器中选择该 JSON 文件（最多 10 MB），系统会自动完成增量合并与落库。
- **CG1 分段记录码**：支持将数据压缩为纯文本记录码（基于 Base64 与 FNV-1a 校验），方便在不便传文件的移动端或聊天工具中跨端复制与导入。
- **增量合并规则**：导入时采用智能合并策略，逐题保留较新记录并去重复习日志，导入的新改动会更新时间戳，联网后可自动覆盖远端较旧的云端状态。

### 2. GitHub Gist 云同步（可选多设备自动同步）
- 在设置 →「云同步」中配置具备 `gist` 权限的 GitHub Token，即可自动在个人 GitHub 账号下创建私密 Gist（`control-daguan-progress.json`）。
- **隐私安全**：令牌只保存在本浏览器的本地 IndexedDB 中，仅直连 `api.github.com`，不上传到本站或代码仓库。
- **自动防抖与双向合并**：本地做题、标记或笔记改动后约 3 秒自动防抖同步；打开页面或联网时自动拉取远端改动并双向合并。
- **离线断网容错**：离线时改动照常保存在本地，恢复联网后自动触发补同步。
